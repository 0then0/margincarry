# MarginCarry v0.6.0

Transfer highlights and underlines between two local PDFs attached to separate items in the same writable personal Zotero library. Select both attachments, review the proposed matches, and confirm the direction. The dialog identifies both records and files. If either PDF moves to another item during review, run the analysis again.

MarginCarry adds copies to the target PDF and keeps the original annotations. Repeat protection and Undo use the existing transfer journal. Note copying remains available for transfers within the note's own item.

## Installation

Download `margincarry-0.6.0.xpi` below and install it through **Tools → Plugins → Install Plugin From File…**. This release supports Zotero 10.0.5 through 10.0.x.

## Verification

In an isolated Zotero 10.0.9 profile on macOS, a reader-created LoRA highlight transferred from arXiv v2 to the ICLR 2022 PDF and appeared at the expected position after reopening. A second check covered identical PDF labels, underline transfer, duplicate rejection, and changing the target's parent after review. Undo removed only the transferred copy.
