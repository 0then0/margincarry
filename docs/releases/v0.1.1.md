# MarginCarry v0.1.1

This patch publishes the completed native validation evidence and improves the development validation harness. Annotation matching and transfer behavior are unchanged from v0.1.0.

## Installation

Download `margincarry-0.1.1.xpi` below. In Zotero, open **Tools → Plugins → Install Plugin From File…** and select the XPI. Restart Zotero after installation. The neighboring `.sha256` file records the package checksum.

## Changes

- Published reader-created annotation checks and live highlight/underline overlays for all four known LoRA geometry outliers.
- Corrected custom validation paths, independent metadata assertions, and repeat-protection checks against full target and journal snapshots.
- Serialized host bridge requests to prevent concurrent requests from receiving each other's results.
- Updated the host installer to select the package matching the current manifest version.

## Verification and limits

All 73 automated tests, strict TypeScript, Biome, and XPI packaging pass. The runtime bundle is unchanged from the published v0.1.0 package. Native checks exercised that v0.1.0 package on **Zotero 10.0.6**, **macOS 15.7.9**, **Apple Silicon**; the v0.1.1 package has not been separately installed for native testing.

The frozen corpus still has 23 positive cases and nine untransferred cases, with no wrong recommendations. Four strict rectangle-boundary discrepancies remain among the 120 LoRA alternatives, and the supplementary `pa- / rameters` case retains its recorded boundary discrepancy. Live overlays for the original four match native reader geometry; the strict scorer and historical results have not been relaxed. Review selected locations before confirming a transfer.

See the [native validation follow-up](https://github.com/0then0/margincarry/blob/v0.1.1/docs/native-v010-followup.md) for evidence and remaining limits. Windows, Linux, and other hosts have not been verified. Supported scope remains continuous one-page highlights and underlines between local PDF revisions of the same item in a personal library.
