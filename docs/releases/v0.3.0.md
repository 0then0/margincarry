# MarginCarry v0.3.0

After transferring annotations between two PDF revisions, select a child note in your personal library and open **Tools → MarginCarry: copy note with links to the new PDF…**. Choose the completed transfer and preview the links. MarginCarry shows the old and new page labels and marks links without a confirmed match.

Save to create a new child note with updated links to the matched highlights and underlines. The copy keeps the quoted text, comments, formatting, and other links. The original note and both PDFs are unchanged. If the note or the confirmed links change after the preview, review the links again before saving.

## Installation

Download `margincarry-0.3.0.xpi` below. In Zotero, open **Tools → Plugins**, choose **Install Plugin From File…** from the gear menu, and select the XPI. This release supports Zotero 10.0.5 through 10.0.x. The accompanying `.sha256` file records the package checksum.

## Verification

In an isolated Zotero 10.0.8 profile on macOS, the original note opened its highlight on page 1 of the old PDF and the copied note opened the transferred highlight on page 2 of the new PDF. Text and formatting survived reopening the copy. Switching notes in the dialog cleared the previous preview before saving the newly selected note.
