# MarginCarry v0.7.0

Copy a child note from a preprint to the Zotero item holding the published PDF after an annotation transfer. The preview names both items and PDFs, shows the note's destination, and identifies links without a confirmed match. Save requires at least one confirmed link.

In the copied note, **Show on Page** (called **Go to Page** in Zotero 10.0.9) opens the transferred annotation in the target PDF. **Show Item** on its citation opens the source item, and the citation keeps its original page number. Undo moves the transferred annotation to Trash and retains the copied note.

## Installation

Install `margincarry-0.7.0.xpi` via **Tools → Plugins → Install Plugin From File…**. This release supports Zotero 10.0.5 through 10.0.x.

## Verification

In an isolated Zotero 10.0.9 profile on macOS, the LoRA arXiv v2 note cited page 8 while its copied highlight opened page 7 of the ICLR 2022 PDF. After Undo, the copied link still opened page 7 without the transferred highlight.
