# MarginCarry v0.1.0

Carry native highlights and underlines between two local PDF revisions of the same Zotero item. Compare actual PDF previews, choose ambiguous locations, and explicitly confirm the selected transfers.

## Installation

Download `margincarry-0.1.0.xpi` below. In Zotero, open **Tools → Plugins → Install Plugin From File…** and select the XPI. Restart Zotero after installation to refresh cached interface styles. The neighboring `.sha256` file records the package checksum.

## Included

- English and Russian interface with explicit language buttons.
- Exact and conservative normalized matching, context, and explicit alternative selection.
- Native annotation copies with new keys, original comments, colors, and text tags.
- Revision checks, atomic writes, repeat protection, and conflict-aware undo.

## Verification and limits

Verified on **Zotero 10.0.5**, **macOS 15.7.9**, **Apple Silicon**. Other hosts are not declared tested. All 65 automated tests, strict TypeScript, Biome, and XPI packaging pass. Native validation covers apply, restart, repeat protection, and undo; the two real revision pairs contain 32 source cases.

There are 23 positive cases with a correct proposal and nine untransferred cases. Four rectangle-boundary discrepancies remain among the 120 alternatives for the short LoRA quote; none is automatically recommended. Visually review each selected position.

v0.1 supports continuous one-page native highlights and underlines in a personal library. OCR, fuzzy matching, multi-page or discontinuous selections, group libraries, and note-link rewriting are outside scope. Internal Zotero reader APIs may change in future host releases.

See the README and engineering report for the workflow, data handling, complete corpus results, and limitations.
